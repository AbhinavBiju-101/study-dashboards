{% call sec('m5-1','1','Qubits: from the bit to the quantum bit') %} {% call sub('m5-1-1','1.1','Classical bit versus qubit') %}
Why it matters. A classical computer is built from objects that are either 0 or 1. Shrinking transistors toward atomic size means quantum effects can no longer be ignored (your notes file, on the end of Moore's law), so the idea is to use them instead. The qubit is the unit that makes this possible.
{% call box('def') %}A bit is an object with two distinct states, 0 and 1 (for example, low or high voltage), and it is in exactly one of them at a time. A qubit (quantum bit) is a quantum system with two basis states |0⟩ and |1⟩ that can also be in a superposition α|0⟩ + β|1⟩ of them, with α and β complex numbers, until it is measured. A measurement always returns a definite 0 or 1.{% endcall %}

{% call box('mis') %}"A qubit is both 0 and 1, so it stores two bits." Before measurement it has a definite state (a vector); on measurement you get one bit. Two things from your deck's table deserve care. It says a qubit has "infinite information density" because its amplitudes are continuous; but you only ever read out a single 0 or 1. And "n qubits can hold all 2ⁿ values at once" means the state has 2ⁿ amplitudes, not that you can read all 2ⁿ values out (the notes file's "a 4-qubit register can store all 16 numbers" should be read in this sense).{% endcall %}
Next: 1.2 writes down what a qubit actually is as a vector.
{% endcall %}
{% call sub('m5-1-2','1.2','The qubit as a vector in Hilbert space') %}
Why it matters. This is Module 2 again: a qubit is a unit vector in a two-dimensional complex vector space, and |0⟩, |1⟩ are an orthonormal basis of it. Everything later is matrix algebra on 2-component columns.
{% call box('def') %}The two computational basis states are the column vectors |0⟩ = (1, 0)ᵀ and |1⟩ = (0, 1)ᵀ. They are orthonormal (⟨0|0⟩ = ⟨1|1⟩ = 1, ⟨0|1⟩ = 0) and span the two-dimensional Hilbert space of the qubit. A general qubit state is |ψ⟩ = α|0⟩ + β|1⟩ = (α, β)ᵀ. Physical choices for |0⟩ and |1⟩ (your slide 6): spin up/down of a nucleus or electron; no photon / one photon in a cavity; ground / excited atomic level; horizontal / vertical photon polarisation; also superconducting circuits and trapped ions.{% endcall %} {% call fig('Two physical encodings of one qubit. Left: energy levels (ground state |0⟩, excited state |1⟩, gap ΔE = E₁ − E₀). Right: spin down/up. Notice the maths is identical whichever encoding is used; only the labelling differs.') %} {% endcall %} {% call box('ex') %}
Problem. Write |ψ⟩ = (3/5)|0⟩ + (4i/5)|1⟩ as a column vector, check it is a valid qubit state, and give the measurement probabilities.
|ψ⟩ = (3/5, 4i/5)ᵀ. Norm: |α|² + |β|² = 9/25 + |4i/5|² = 9/25 + 16/25 = 1, so it is a valid state.
P(0) = |α|² = 0.36; P(1) = |β|² = 0.64. The i in β does not change the probabilities (|i|² = 1); it is a relative phase.
Check. 0.36 + 0.64 = 1 ✓. Using the bra: ⟨ψ| = (3/5, −4i/5), so ⟨ψ|ψ⟩ = 9/25 + (−4i/5)(4i/5) = 9/25 + 16/25 = 1 ✓ (the conjugate matters: without it you would get 9/25 − 16/25).
{% endcall %} {% call box('mis') %}"Normalised means α + β = 1." The condition is on squared moduli: |α|² + |β|² = 1. The state (1/2)|0⟩ + (1/2)|1⟩ has α + β = 1 but is not normalised (its norm² is 1/2).{% endcall %}
Next: 1.3 gets the physics of superposition and measurement.
{% endcall %}
{% call sub('m5-1-3','1.3','Superposition, amplitudes and measurement') %}
Why it matters. Superposition is not "the qubit secretly being 0 or 1". The amplitudes can interfere (as waves do), which is why different gates give different final results. Measurement then turns the amplitudes into probabilities (Module 3, postulates).
{% call box('def') %}Because the Schrödinger equation is linear, any linear combination of allowed states is an allowed state (your slide 7): this is superposition. In |ψ⟩ = α|0⟩ + β|1⟩, α and β are probability amplitudes. Measuring in the {|0⟩, |1⟩} basis gives 0 with probability |α|² and 1 with probability |β|², and the state collapses to the result: afterwards it is |0⟩ or |1⟩, so repeating the measurement gives the same answer. The two special states |±⟩ = (|0⟩ ± |1⟩)/√2 are equal superpositions.{% endcall %}

|+⟩ and |−⟩ give the same measurement probabilities in the {|0⟩,|1⟩} basis but are different states: they differ by a relative sign (phase), which later gates can detect.

{% call box('ex') %}
Problem. A qubit is in |ψ⟩ = (1/√3)|0⟩ + √(2/3) eiπ/4|1⟩. Find P(0) and P(1). After a measurement that gives 1, what is the state and what would a second measurement give?
|α|² = 1/3; |β|² = 2/3 (the phase factor has modulus 1). So P(0) = 1/3, P(1) = 2/3.
After getting 1 the state is |1⟩ (collapse); a second measurement gives 1 with probability 1.
Check. 1/3 + 2/3 = 1 ✓ so the state was normalised. Collapse is the same measurement postulate as Module 3, 3.
{% endcall %} {% call box('mis') %}"Superposition means the qubit is in many states until measured and we just don't know which." The standard picture is not ignorance about a hidden value: the superposition itself is the state, and its phases matter for what later gates do. Deck's dimmer-switch picture: the qubit is anywhere between fully off and fully on, but a measurement is always a definite off or on.{% endcall %}
Next: 1.4 is a first look at entanglement, developed fully in Section 4.
{% endcall %}
{% call sub('m5-1-4','1.4','Entanglement: a first look') %}
Why it matters. Superposition alone could be imitated by tricks with probabilities; entanglement cannot. Together they are what the deck gives as the source of quantum computing's power.
{% call box('def') %}Two or more qubits are entangled when their joint state cannot be written as a separate state for each qubit. Each qubit alone has no definite value, but the joint state is well defined and the outcomes are strongly correlated (your slide 25: "the entanglement lies not in the values themselves, but in the correlation between the values"). Entanglement can occur naturally (for example atomic decay) or be created with optical techniques such as parametric down-conversion, with quantum gates such as CNOT, or with laser or microwave control. The deck's coin analogy: two independent fair coins both show heads with probability 1/4; for "linked" coins it is 1/2.{% endcall %} {% call box('mis') %}"Measuring one entangled qubit sends a signal to the other." The deck says measuring one qubit "instantly influences" the other. The correlation is real, but each person's own results are still random (50% 0, 50% 1 for the state in 4.2), so the other end learns nothing until the results are compared by ordinary communication. This no-signalling remark is my addition (it is standard quantum mechanics), not from your deck; it is the safe way to phrase an exam answer.{% endcall %}

{% call sub('m5-2-1','2.1','What the Bloch sphere is') %}
Why it matters. A qubit state has two complex numbers α and β, which is hard to picture. After removing two redundancies (normalisation and an overall phase), what is left is just two angles, so every qubit state is a point on an ordinary sphere. Gates then become rotations you can see.
{% call box('def') %}The Bloch sphere is a unit sphere whose surface points correspond one-to-one to the pure states of a single qubit. The north pole is |0⟩ (the +z direction) and the south pole is |1⟩. Every other point is a superposition of |0⟩ and |1⟩. The state is drawn as a unit vector from the centre to the surface point. Applying a quantum gate corresponds to rotating this vector.{% endcall %} {% call fig('Bloch sphere with the state vector |ψ⟩ at polar angle θ from the +z axis and azimuth φ from the +x axis. Notice the poles are |0⟩ and |1⟩, and the equator (θ = π/2) holds the equal superpositions.') %} {% endcall %}

{% call box('mis') %}"Orthogonal states are at right angles on the Bloch sphere." Orthogonal qubit states are at opposite points (180° apart): |0⟩ and |1⟩ are the two poles, |+⟩ and |−⟩ the two ends of the x axis. The sphere's angle is twice the "Hilbert-space angle" (this follows from the θ/2 in the formula below).{% endcall %}
Next: 2.2 gives the formula that turns angles into amplitudes.
{% endcall %}
{% call sub('m5-2-2','2.2','Coordinates, the state formula and special points') %}
Why it matters. This is the formula the exam will ask you to use: convert (θ, φ) to amplitudes and probabilities, and back.
{% call box('def') %}θ is the polar angle from the +z axis (0 ≤ θ ≤ π) and φ the azimuthal angle from the +x axis in the xy plane (0 ≤ φ < 2π). The general pure qubit state is |ψ⟩ = cos(θ/2)|0⟩ + eiφ sin(θ/2)|1⟩, and the Bloch vector is r = (sin θ cos φ, sin θ sin φ, cos θ). So θ controls how much of |0⟩ against |1⟩ there is, and φ the relative phase between them. Measurement probabilities: P(0) = cos²(θ/2) = (1 + cos θ)/2, P(1) = sin²(θ/2) = (1 − cos θ)/2 (the last forms follow from the double-angle identity).{% endcall %}

{% call sub('m5-3-1','3.1','The tensor product and the computational basis') %}
Why it matters. This is Module 2, tensor product of vector spaces, applied: two 2-dimensional spaces combine into one 4-dimensional space, not a 2 + 2 = 4 by addition but 2 × 2 = 4 by multiplication. That multiplication is why n qubits need 2ⁿ numbers.
{% call box('def') %}For qubits A and B the joint space is H_A ⊗ H_B with dimension 2 × 2 = 4. The four computational basis states are the tensor products of the single-qubit ones: |0⟩⊗|0⟩ = |00⟩, |0⟩⊗|1⟩ = |01⟩, |1⟩⊗|0⟩ = |10⟩, |1⟩⊗|1⟩ = |11⟩, with column vectors |00⟩ = (1,0,0,0)ᵀ, |01⟩ = (0,1,0,0)ᵀ, |10⟩ = (0,0,1,0)ᵀ, |11⟩ = (0,0,0,1)ᵀ. The first label is qubit A, the second is B. For n qubits the space has dimension 2ⁿ. The notation H₍₂₎ means "tensor product of order two" and is not a dimension-2 space (the dimension is still 4).{% endcall %}

For |+⟩⊗|0⟩: a = b = 1/√2, c = 1, d = 0, so |ψ⟩ = (1/√2)|00⟩ + (1/√2)|10⟩ = (|00⟩ + |10⟩)/√2, as the column (1/√2)(1, 0, 1, 0)ᵀ.

{% call sub('m5-3-2','3.2','General two-qubit state and measurement probabilities') %}
Why it matters. A general two-qubit state has four complex amplitudes. Most of them are not a simple product of two single-qubit states, which is where entanglement comes from (Section 4).
{% call box('def') %}A general two-qubit state is |Ψ⟩ = α₀₀|00⟩ + α₀₁|01⟩ + α₁₀|10⟩ + α₁₁|11⟩ with |α₀₀|² + |α₀₁|² + |α₁₀|² + |α₁₁|² = 1. Measuring both qubits gives |αᵢⱼ|² for outcome ij. The probability that the first qubit alone reads 0 is |α₀₀|² + |α₀₁|², and then the state collapses to the part with first qubit 0, renormalised.{% endcall %} {% call box('ex') %}
Problem. |Ψ⟩ = (|00⟩ + |01⟩ + |10⟩)/√3. Find the probability of each outcome, the probability that the first qubit is 0, and the state after the first qubit is measured as 0.
Each present basis state has amplitude 1/√3, so P(00) = P(01) = P(10) = 1/3 and P(11) = 0.
First qubit = 0 corresponds to |00⟩ and |01⟩: P = 1/3 + 1/3 = 2/3.
Keep only those terms: (|00⟩ + |01⟩)/√3, then renormalise by dividing by √(2/3): (|00⟩ + |01⟩)/√2 = |0⟩⊗|+⟩.
Check. 3 × 1/3 = 1 ✓. After collapse the second qubit is |+⟩, so measuring it next gives 0 or 1 with 50% each ✓ (amplitudes 1/√2 each). The renormalisation step is the same as the collapse postulate of Module 3.
{% endcall %} {% call box('mis') %}"Independent measurements: P(first = 0) × P(second = 0) = P(00)." That multiplication rule (the one used on your slide 18 for independent qubits) holds only for product states. For the state above, P(first = 0) × P(second = 0) = (2/3)(2/3) = 4/9, but P(00) = 1/3: so the qubits are not independent (this state is entangled).{% endcall %}

{% call sub('m5-4-1','4.1','Product states versus entangled states') %}
Why it matters. Some two-qubit states are just two independent qubits side by side. Others cannot be split. You need a quick test to tell which is which.
{% call box('def') %}A two-qubit state is a product state if it can be written |ψ₁⟩ ⊗ |ψ₂⟩; otherwise it is entangled. From 3.1, a product state has amplitudes (ac, ad, bc, bd), so α₀₀α₁₁ = α₀₁α₁₀. If this equality fails, the state is entangled. (This test follows directly from the slide-23 expansion; it is my packaging of it, not a statement in the deck.){% endcall %}

Problem. Show that (|00⟩ + |11⟩)/√2 cannot be written as (a|0⟩ + b|1⟩)⊗(c|0⟩ + d|1⟩).
A product has amplitudes ac, ad, bc, bd. We need ad = 0 (no |01⟩ term) and bc = 0 (no |10⟩ term), but ac = bd = 1/√2 ≠ 0.
ad = 0 means a = 0 or d = 0. If a = 0 then ac = 0, a contradiction; if d = 0 then bd = 0, a contradiction. So no such a, b, c, d exist: the state is entangled.
Check. Same conclusion as the test: α₀₀α₁₁ = 1/2 ≠ α₀₁α₁₀ = 0 ✓.
{% endcall %} {% call box('mis') %}"Any superposition of two basis states is entangled." (|00⟩ + |10⟩)/√2 is a superposition of two basis states, but it factors as |+⟩|0⟩, so it is a product state. Entanglement is about whether the state factors, not how many terms it has.{% endcall %}

Why it matters. The Bell states are the standard "most entangled" two-qubit states and the examples every question uses. They also form a complete orthonormal basis of the two-qubit space.

{% call sub('m5-4-3','4.3','Correlations, applications and experiments') %}
Why it matters. "State two applications of Bell states or entanglement" is a standard short question; your deck lists them on slide 29.

{% call sub('m5-5-2','5.2','Pauli-X gate (the quantum NOT)') %}
Why it matters. X is the simplest gate and the template for proving what any gate does: write the matrix, write the state, multiply, read off the result (your slide 36 lists exactly these steps).

{% call sub('m5-6-1','6.1','The CNOT gate') %}
Why it matters. CNOT is the standard two-qubit gate: it makes one qubit's value depend on another. With single-qubit gates it builds any computation, and it is how entanglement is produced.
{% call box('def') %}CNOT (controlled-NOT) has a control qubit (first) and a target qubit (second). If the control is |1⟩ it applies X to the target; if the control is |0⟩ it leaves the target alone.
