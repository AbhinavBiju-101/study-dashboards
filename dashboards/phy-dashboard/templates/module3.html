{% call sec('m3-1','1','Observables and operators') %} {% call sub('m3-1-1','1.1','What an observable is') %}
Why it matters. Classically a quantity such as position simply has a value. Quantum mechanics replaces "the value" with an operator, and the value you get in a measurement is then decided by that operator's eigenvalues. Every later section builds on this switch.
{% call box('def') %}An observable is a physical property that can be measured (position, momentum, energy, angular momentum). In quantum mechanics each observable is represented by a Hermitian operator acting on states in a Hilbert space. Because measured values are real, the operator must have only real eigenvalues, and Hermitian operators guarantee that (Module 2, 4.3). The state of the system, with all the information you can know about it, is a normalised ket (Postulate 1 in the Stern-Gerlach chapter you were given).{% endcall %}
Classical mechanicsQuantum mechanics
Stateexact values of position and momentumnormalised ket |ψ⟩ or wavefunction ψ(x)
Observablea number computed from the statea Hermitian operator
Result of a measurementthe value, determined by the stateone eigenvalue, with a probability
{% call box('ex') %}
Problem. Which of Â = [[1, 2],[2, 3]], B̂ = [[0, i],[i, 0]], Ĉ = [[2, 1−i],[1+i, 1]] can represent an observable?
Â is real and symmetric, so Â† = Â: Hermitian ✓. B̂† = [[0, −i],[−i, 0]] ≠ B̂: not Hermitian ✗. Ĉ: the (1,2) entry 1−i is the conjugate of the (2,1) entry 1+i and the diagonal is real, so Ĉ† = Ĉ ✓.
Check with eigenvalues. B̂ has det = 0 − i·i = 1 and trace 0, so λ² + 1 = 0, λ = ±i: imaginary, so it cannot be a measurement result, confirming the verdict. Ĉ: trace 3, det 2 − 2 = 0, so λ = 0, 3 (both real ✓).
{% endcall %} {% call box('mis') %}"An operator is an observable if it has a nice physical meaning." The condition is mathematical: Hermitian. Also "the observable is the number": the number is one outcome; the observable is the operator that lists all the possible outcomes.{% endcall %}

Problem. Apply p̂ₓ and T̂ to f(x) = eikx and to g(x) = sin(3x).
p̂ f = −iħ (ik eikx) = ħk eikx. T̂ f = −(ħ²/2m)(ik)² eikx = (ħ²k²/2m) eikx. So f is an eigenfunction of both, with p = ħk and T = ħ²k²/2m.

Why it matters. The operators are not arbitrary: they are what you get by asking "what do I do to a plane wave to pull out p or E?"

{% call sub('m3-1-4','1.4','The eigenvalue postulate and quantised results') %}
Why it matters. This is the origin of quantisation: if only eigenvalues can be observed, and an operator has a discrete list of eigenvalues, then the measured quantity is discrete. The energies of the box in Module 4 are exactly such a list.
{% call box('def') %}In any measurement of the observable associated with Ĝ, the only values ever observed are the eigenvalues Gₙ of the eigenvalue equation Ĝ ψₙ = Gₙ ψₙ. The state ψₙ is the eigenstate (eigenfunction, eigenvector). It is a state with a definite value Gₙ: measuring gives Gₙ with certainty. The index n (a quantum number) labels the whole family of solutions.{% endcall %}
StepWhat to do
1Write the operator Ĝ for the observable
2Solve Ĝψ = Gψ for the allowed G (eigenvalues) and ψ (eigenstates)
3Possible measurement outcomes = the eigenvalues; states with a certain outcome = the eigenstates
{% call box('ex') %}
Problem. Show ψ = sin(3x) is an eigenfunction of Ĝ = d²/dx² and find the eigenvalue. Is ψ = sin(3x) + cos(2x) one?
d²/dx² sin 3x = −9 sin 3x, so it is an eigenfunction with eigenvalue −9.
d²/dx² [sin 3x + cos 2x] = −9 sin 3x − 4 cos 2x, which is not a single constant times the original. So the sum is not an eigenfunction.
Check. Try to force a constant: −9 sin3x − 4cos2x = λ(sin3x + cos2x) needs λ = −9 and λ = −4 simultaneously: impossible ✓. The sum is a superposition; measuring Ĝ on it could give −9 or −4, with probabilities set in Section 3.
{% endcall %} {% call box('mis') %}"A superposition of eigenstates is also an eigenstate." Only if they share the same eigenvalue. Otherwise the state has no single value for that observable until measured.{% endcall %}

{% call sec('m3-2','2','Expectation values') %} {% call sub('m3-2-1','2.1','Meaning of an expectation value') %}
Why it matters. Quantum mechanics predicts probabilities, so what an experiment can actually compare with theory is an average over many identical trials.
{% call box('def') %}The expectation value ⟨A⟩ of an observable in a state is the probability-weighted average of the values you would obtain from many measurements on identically prepared systems. It is not necessarily the most probable value, and may not even be a possible result. Classical version: x̄ = ΣNᵢxᵢ / ΣNᵢ, i.e. Σ xᵢPᵢ with Pᵢ = Nᵢ/N. For a continuous position, Pᵢ → |ψ|²dx, so ⟨x⟩ = ∫x|ψ|²dx with ∫|ψ|²dx = 1.{% endcall %} {% call fig('A distribution with mean ⟨x⟩ marked. Notice the mean need not sit where the curve is highest, and for a two-peaked distribution it can sit in a valley where the particle is never found.') %} {% endcall %} {% call box('ex') %}
Problem. Ten identical particles are found at positions: three at x = 1, five at x = 2, two at x = 6 (metres). Find the average, then the probabilities Pᵢ and Σ xᵢPᵢ.
x̄ = (3·1 + 5·2 + 2·6)/10 = (3 + 10 + 12)/10 = 2.5.
Pᵢ = 0.3, 0.5, 0.2, so ΣxᵢPᵢ = 0.3 + 1.0 + 1.2 = 2.5.
Check. Both routes give 2.5 ✓, and 2.5 is not one of the measured positions: an average need not be a possible result.
{% endcall %} {% call box('mis') %}"The expectation value is what you will measure." A single measurement gives one eigenvalue. For a spin-½ in a state with ⟨σ_z⟩ = 0, no measurement ever gives 0; it gives +1 or −1.{% endcall %}

{% call sub('m3-2-2','2.2','Computing ⟨x⟩, ⟨p⟩ and ⟨E⟩') %}
Why it matters. This is the most common numerical question of the module, and it reuses the operators from 1.2.
{% call box('def') %}For a normalised ψ: ⟨x⟩ = ∫ψ* x ψ dx, ⟨p⟩ = ∫ψ* (−iħ ∂/∂x) ψ dx, ⟨E⟩ = ∫ψ* Ĥ ψ dx (or iħ∫ψ*∂ψ/∂t dx). General rule: ⟨Â⟩ = ∫ψ* Âψ dx, with the operator sandwiched between ψ* and ψ and acting only on ψ. For a free particle ψ = Aeipx/ħ, ⟨p⟩ = p. Always normalise ψ first. In Dirac notation ⟨Â⟩ = ⟨ψ|Â|ψ⟩.{% endcall %} {% call box('ex') %}
Problem. A particle has ψ(x) = √30 x(1−x) for 0 ≤ x ≤ 1 and 0 elsewhere. Find ⟨x⟩.
Normalised already (Module 2, 2.2: ∫x²(1−x)²dx = 1/30, so the factor √30 is right).
⟨x⟩ = 30∫₀¹ x·x²(1−x)² dx = 30∫(x³ − 2x⁴ + x⁵)dx = 30(1/4 − 2/5 + 1/6) = 30·(15 − 24 + 10)/60 = 30·(1/60) = 1/2.
Check. ψ² = 30x²(1−x)² is symmetric about x = ½ (swap x ↔ 1−x), so the average position must be ½ ✓.
{% endcall %} {% call box('mis') %}"Use an unnormalised ψ; the constant cancels." It does not: ∫ψ*xψ scales with |A|². Either normalise first or divide by ∫|ψ|²dx. Also never move the operator to the left of ψ*: ψ* p̂ ψ ≠ p̂ ψ* ψ.{% endcall %}

{% call sub('m3-2-3','2.3','Shortcuts for real wavefunctions and ⟨p²⟩') %}
Why it matters. Box wavefunctions (Module 4) are real, so ⟨p⟩ is zero at once, and ⟨p²⟩ can be found without differentiating twice.
{% call box('def') %}If ψ is real (and vanishes at the ends or at infinity), then ⟨p⟩ = (ħ/i)∫ψψ′dx = (ħ/2i)[ψ²] = 0. For ⟨p²⟩ integrate by parts: ⟨p²⟩ = ħ²∫|dψ/dx|² dx (boundary terms vanish). Also, ⟨x²⟩ ≠ ⟨x⟩² in general.{% endcall %} {% call box('why','Why ⟨p⟩ = 0 for real ψ') %}ψψ′ = ½ d(ψ²)/dx is a total derivative, so ∫ψψ′dx = ½[ψ²] evaluated between the ends, which is 0 when ψ vanishes there. The factor ħ/i does not change zero. (Your slides show this for the box and for the oscillator ground state.){% endcall %} {% call box('ex') %}
Problem. For ψ = √30 x(1−x) find ⟨p⟩ and ⟨p²⟩.
ψ is real and ψ(0) = ψ(1) = 0, so ⟨p⟩ = 0.
ψ′ = √30(1 − 2x), so ⟨p²⟩ = ħ²·30∫₀¹(1 − 2x)²dx. ∫(1 − 4x + 4x²)dx = 1 − 2 + 4/3 = 1/3. Hence ⟨p²⟩ = 30ħ²/3 = 10ħ².
Check. Second route: ψ″ = −2√30, so ⟨p²⟩ = −ħ²∫ψψ″dx = −ħ²·(−2)·30∫x(1−x)dx = 60ħ²(1/2 − 1/3) = 60ħ²/6 = 10ħ² ✓.
{% endcall %} {% call box('mis') %}"⟨p²⟩ = ⟨p⟩² = 0." Wrong: ⟨p⟩ = 0 but ⟨p²⟩ = 10ħ² > 0. This gap between ⟨p²⟩ and ⟨p⟩² is exactly the uncertainty in p (next subsection).{% endcall %}

{% call sub('m3-2-4','2.4','Uncertainty from expectation values') %}
Why it matters. The spread of results is as physical as their average, and the Heisenberg bound ΔxΔp ≥ ħ/2 is your check that a calculation is sensible. In Module 4 this is why the box has zero-point energy.
{% call box('def') %}Δx = √(⟨x²⟩ − ⟨x⟩²), Δp = √(⟨p²⟩ − ⟨p⟩²). The uncertainty principle: ΔxΔp ≥ ħ/2. (For the harmonic-oscillator ground state, your slides get ΔxΔp = ħ/2 exactly.){% endcall %} {% call fig('Narrow in x means broad in p, and vice versa. Both sketches obey ΔxΔp ≥ ħ/2. Notice that squeezing one distribution widens the other.') %} {% endcall %} {% call box('ex') %}
Problem. For ψ = √30 x(1−x) find Δx, Δp and test the principle.
⟨x²⟩ = 30∫(x⁴ − 2x⁵ + x⁶)dx = 30(1/5 − 1/3 + 1/7) = 30·(21 − 35 + 15)/105 = 30/105 = 2/7. With ⟨x⟩ = 1/2: Δx² = 2/7 − 1/4 = 1/28, so Δx = 1/√28 ≈ 0.189.
⟨p⟩ = 0 and ⟨p²⟩ = 10ħ², so Δp = √10 ħ ≈ 3.162ħ.
ΔxΔp = √(10/28) ħ = 0.598ħ.
Check. 0.598ħ ≥ 0.5ħ ✓, so the result is consistent with the uncertainty principle (values also confirmed by numerical integration).
{% endcall %} {% call box('mis') %}"Δx = ⟨x²⟩ − ⟨x⟩²." That is the variance; take the square root. Getting ΔxΔp < ħ/2 always signals an arithmetic error.{% endcall %}

Problem. Find the possible results and definite states for σ_x.
σ_x = [[0,1],[1,0]]: det(σ_x − λI) = λ² − 1 = 0, so λ = ±1. For +1: −v₁ + v₂ = 0, v = (1,1)/√2. For −1: v₁ + v₂ = 0, v = (1,−1)/√2.

{% call sub('m3-3-2','3.2','Probabilities from projection operators') %}
Why it matters. This is the rule that makes quantum mechanics predictive. It reuses the projection operator of Module 2, 4.5 and is the tool behind every Stern-Gerlach count in Section 4.
{% call box('def') %}For a normalised |ψ⟩ and a non-degenerate eigenvector |aₙ⟩ of the measured observable, with projector P̂ₙ = |aₙ⟩⟨aₙ|: Prob(aₙ) = ⟨ψ|P̂ₙ|ψ⟩ = ‖P̂ₙψ‖² = |⟨aₙ|ψ⟩|². The number ⟨aₙ|ψ⟩ is the probability amplitude. Probabilities add to 1: Σ|cₙ|² = 1. Example from your slides: for |ψ⟩ = a|0⟩ + b|1⟩ and P̂₀ = |0⟩⟨0|, Prob(0) = |a|².{% endcall %} {% call fig('The probability of an outcome is the squared length of the shadow of |ψ⟩ on that outcome\'s eigenvector. Notice the two probabilities are cos²θ and sin²θ, which add to 1 (Pythagoras).') %} {% endcall %} {% call box('ex') %}
Problem. The state is |ψ⟩ = (1, 2)ᵀ/√5. σ_x is measured. Find the probability of each result and ⟨σ_x⟩.
Eigenvectors (3.1): |+ₓ⟩ = (1,1)/√2 and |−ₓ⟩ = (1,−1)/√2. Amplitudes: ⟨+ₓ|ψ⟩ = (1 + 2)/(√2√5) = 3/√10, ⟨−ₓ|ψ⟩ = (1 − 2)/√10 = −1/√10.
Probabilities: 9/10 for +1 and 1/10 for −1. ⟨σ_x⟩ = (9/10)(+1) + (1/10)(−1) = 4/5.
Check. 9/10 + 1/10 = 1 ✓. Direct: ⟨ψ|σ_x|ψ⟩ = (1/5)(1, 2)·(2, 1) = (1·2 + 2·1)/5 = 4/5 ✓. Projector route: P₊ = ½[[1,1],[1,1]], P₊ψ = (3/2, 3/2)/√5, ‖P₊ψ‖² = (9/4 + 9/4)/5 = 9/10 ✓.
{% endcall %} {% call box('mis') %}"Probability is the amplitude." It is the amplitude's squared modulus. The −1/√10 above is negative, yet the probability is +1/10. Also the formula needs a normalised ψ; otherwise divide by ⟨ψ|ψ⟩.{% endcall %}

{% call sub('m3-3-3','3.3','Collapse and repeated measurement') %}
Why it matters. This explains Stern-Gerlach experiment 1 (repeat the same measurement, get the same answer) and, together with incompatibility, experiment 3.
{% call box('def') %}When a measurement of Â gives the result aₙ, the state afterwards is the eigenvector |aₙ⟩ (the state is projected, or collapses): |ψ⟩ → P̂ₙ|ψ⟩/‖P̂ₙψ‖. Measuring Â again immediately gives aₙ with probability 1. The first analyser in a Stern-Gerlach chain is therefore a state-preparation device. Measuring a different, non-commuting observable then re-randomises the first one.{% endcall %} {% call fig('Measurement as a two-step picture: a superposition goes in, one eigenvector comes out, chosen with the probability from 3.2. Notice that repeating the measurement (bottom) just returns the same eigenvector.') %} {% endcall %} {% call box('ex') %}
Problem. Starting from |ψ⟩ = (1,2)ᵀ/√5, σ_x is measured and gives +1. σ_x is then measured again, and finally σ_z is measured. Give the probabilities.
After the +1 result, |ψ⟩ → |+ₓ⟩ = (1,1)/√2 (3.2 gave this outcome probability 9/10).
Second σ_x: probability of +1 is |⟨+ₓ|+ₓ⟩|² = 1; of −1 is 0.

|+⟩, |−⟩spin up / down along z (S_z = ±ħ/2)

Why it matters. This is the equation you solve for the box (Module 4) and for any problem where the potential does not change with time. Its solutions are the eigenfunctions, and the E values that work are the allowed energies.
