{% call sec('m2-1','1','Linear vector spaces') %} {% call sub('m2-1-1','1.1','Vector spaces and scalars') %}
Why it matters. A quantum state can be added to another state and scaled, and the result is again a state (superposition). "Something you can add and scale without leaving the set" is exactly a vector space. We need it before anything else.
{% call box('def') %}A vector space V over a set of scalars is a set of objects (vectors) with addition and scalar multiplication such that the usual arithmetic rules hold: addition is commutative and associative, there is a zero vector 0 with 0 + v = v, the distributive laws hold, and 1·v = v. Sums and scalar multiples of vectors in V stay in V (closure). The scalars are real numbers for a real vector space and complex numbers for a complex one (any field works: ℚ, ℝ, ℂ).{% endcall %}
Is it a vector space?VerdictReason
ℝᵐ (columns of m real numbers)YesAdd entrywise, scale entrywise.
m×n matricesYesAdd entrywise; the zero matrix is the zero vector.
Continuous functions; polynomials; polynomials of degree ≤ nYesThe sum of two such functions is one; the zero function is the zero vector.
Polynomials of degree exactly nNox² + (−x² + 1) = 1 has degree 0: closure fails.
The set of all matrices (any size)NoMatrices of different sizes cannot be added.
{% call box('ex') %}
Problem. Is S = {(x, y) : x + y = 1} a vector space? Is T = {2×2 matrices with trace 0} one?
S: the zero vector (0,0) gives 0 + 0 = 0 ≠ 1, so 0 ∉ S. Not a vector space.
T: if tr A = 0 and tr B = 0 then tr(A + B) = 0 and tr(cA) = c·0 = 0, so T is closed; the zero matrix has trace 0. T is a vector space.
Check. Take (1,0) and (0,1) in S: their sum (1,1) has x + y = 2 ≠ 1, confirming closure fails for S.
{% endcall %} {% call box('mis') %}"A set of arrows is a vector space." Not automatically. What matters is closure and the zero vector; the "arrow" picture is only one example. Quantum kets live in a complex space, so scalars like i are allowed: a state such as (|0⟩ + i|1⟩)/√2 is legitimate.{% endcall %}
Next: 1.2 shows how to build new vectors from a few given ones.
{% endcall %}
{% call sub('m2-1-2','1.2','Linear combinations and span') %}
Why it matters. "The state is a superposition of |0⟩ and |1⟩" is a statement that the state is a linear combination of them. The span answers "which vectors can I reach using only these?"
{% call box('def') %}A vector v is a linear combination of v₁,…,vₙ if v = x₁v₁ + … + xₙvₙ for some scalars xᵢ. The set of all linear combinations is the span of the vectors. If the span is the whole space V, the set is complete for V. In ℝᵐ, writing v as a combination of columns v₁…vₙ means solving the linear system Bx = v, where B has those columns.{% endcall %} {% call fig('Left: two non-parallel vectors a and b reach every point of the plane (the parallelogram builds a + b). Right: parallel vectors reach only a line. Notice that in the right panel the second vector adds nothing new.') %} {% endcall %} {% call box('ex') %}
Problem. With v₁ = (1,0,1) and v₂ = (0,1,1), is (2,3,5) in their span? Is (1,1,3)?
Solve x₁v₁ + x₂v₂ = (x₁, x₂, x₁ + x₂). For (2,3,5): x₁ = 2, x₂ = 3, and the third entry x₁ + x₂ = 5 ✓. So (2,3,5) = 2v₁ + 3v₂.
For (1,1,3): x₁ = 1, x₂ = 1 forces the third entry to be 2, not 3. Contradiction: (1,1,3) is not in the span.
Check. 2(1,0,1) + 3(0,1,1) = (2,0,2) + (0,3,3) = (2,3,5) ✓. Geometrically, the span is the plane z = x + y, and 3 ≠ 1 + 1.
{% endcall %} {% call box('mis') %}"Two vectors always span a plane." Only if they are not parallel. Two collinear vectors span just a line (right panel), which is why we need the independence test in 1.3.{% endcall %}
Next: 1.3 gives the exact test for "no vector in the set is redundant".
{% endcall %}
{% call sub('m2-1-3','1.3','Linear independence') %}
Why it matters. A set with a redundant vector describes the same space with wasted effort, and coordinates with respect to it are not unique. Independence is the condition that removes the waste; it is one half of the definition of a basis (1.4).
{% call box('def') %}Vectors v₁,…,vₙ are linearly independent if x₁v₁ + … + xₙvₙ = 0 forces x₁ = … = xₙ = 0 (equivalently, none is a combination of the others). Otherwise they are dependent. For the columns of a matrix B: independent ⇔ Bx = 0 has only x = 0 ⇔ the row-reduced form has a pivot in every column. For n vectors in ℝⁿ: independent ⇔ det B ≠ 0.{% endcall %}
MethodHowBest when
DefinitionSolve Σxᵢvᵢ = 0; only the trivial solution means independentFunctions and polynomials (compare coefficients)
DeterminantSquare case: det ≠ 0 ⇔ independentn vectors in ℝⁿ or ℂⁿ
Row reductionPivot in every column ⇔ independent; pivot-free columns are the redundant onesAny number of vectors
{% call box('ex') %}
Problem. Are v₁ = (1,2,3), v₂ = (2,1,0), v₃ = (4,5,6) independent?
Determinant test. Put them as columns: det [[1,2,4],[2,1,5],[3,0,6]] = 1(1·6 − 5·0) − 2(2·6 − 5·3) + 4(2·0 − 1·3) = 6 − 2(−3) + 4(−3) = 6 + 6 − 12 = 0. So they are dependent.
Find the relation. Try v₃ = a v₁ + b v₂. Third entry: 3a = 6, so a = 2. First entry: 2 + 2b = 4, so b = 1. Then v₃ = 2v₁ + v₂, i.e. 2v₁ + v₂ − v₃ = 0 (a non-trivial combination giving zero).
Check. Second entry: 2·2 + 1 = 5 ✓ (matches v₃'s 5). Two independent tests (determinant and explicit relation) agree.
{% endcall %} {% call box('mis') %}"Independent means perpendicular." No. (1,0) and (1,1) are independent but not perpendicular. Perpendicularity is the stronger property in 2.1. Also: "three vectors in ℝ² can be independent" is impossible; ℝ² has room for at most 2.{% endcall %}
Next: 1.4 combines independence with completeness to define a basis.
{% endcall %}
{% call sub('m2-1-4','1.4','Basis vectors and dimension') %}
Why it matters. A basis is the coordinate system of a vector space. Choosing |0⟩, |1⟩ (or |+⟩, |−⟩) as a basis for a qubit is exactly this idea, and the Stern-Gerlach experiments in Module 3 are about changing basis.
{% call box('def') %}A basis of V is a set of linearly independent vectors whose span is V (independent and complete). Every basis of V has the same number of vectors, the dimension of V. For an m×m matrix B these are equivalent: columns complete ⇔ columns independent ⇔ columns form a basis ⇔ B is invertible. The standard basis of ℝᵐ is e₁,…,eₘ with a single 1 in position i.{% endcall %} {% call fig('The same vector (3,1) has different coordinates in different bases. Standard basis: (3, 1). Basis {(1,1), (1,−1)}: coordinates (2, 1). The arrow does not change; only its description does.') %} {% endcall %} {% call box('ex') %}
Problem. Show B = {(1,1), (1,−1)} is a basis of ℝ² and find the coordinates of v = (3,1).
Matrix with these columns: [[1,1],[1,−1]], det = −1 − 1 = −2 ≠ 0. Two independent vectors in a 2D space form a basis.
Solve a(1,1) + b(1,−1) = (3,1): a + b = 3 and a − b = 1. Adding: 2a = 4, so a = 2, then b = 1.
Check. 2(1,1) + 1(1,−1) = (2+1, 2−1) = (3,1) ✓. Dimension count: P₂ (polynomials of degree ≤ 2) has basis {1, x, x²}, so dim P₂ = 3.
{% endcall %} {% call box('mis') %}"A vector has one set of coordinates." Coordinates belong to a (vector, basis) pair. Writing |ψ⟩ = (a, b)ᵀ silently assumes a basis. Also, "any n vectors in an n-dimensional space form a basis": only if they are independent.{% endcall %}
Next: 1.5 looks at smaller spaces inside a space, and at the two subspaces every matrix carries.
{% endcall %}
{% call sub('m2-1-5','1.5','Subspaces, column space and null space') %}
Why it matters. Measurement in Module 3 projects a state onto a subspace (the eigenspace of the result). The null space and column space are the standard worked examples of subspaces.
{% call box('def') %}A subspace W of V is a non-empty subset closed under addition and scalar multiplication (so it contains 0). Lines and planes through the origin are subspaces of ℝ³. For a matrix A: the column space C(A) = span of the columns of A (dimension = number of pivots = rank); the null space N(A) = {x : Ax = 0} (dimension = number of free variables = nullity). Rank + nullity = number of columns. A basis for N(A): row-reduce, solve Rx = 0, write the solution in terms of the free variables.{% endcall %} {% call box('ex') %}
Problem. Find a basis for the null space of A = [[1,2,3],[2,4,6]].
Row 2 = 2 × row 1, so row reduction gives R = [[1,2,3],[0,0,0]]. One pivot (column 1), so x₂ and x₃ are free. The equation is x₁ + 2x₂ + 3x₃ = 0, so x₁ = −2x₂ − 3x₃.
x = x₂(−2,1,0) + x₃(−3,0,1). A basis is {(−2,1,0), (−3,0,1)}; they are independent (look at the last two entries).
Check. A(−2,1,0) = (−2+2+0, −4+4+0) = (0,0) ✓; A(−3,0,1) = (−3+0+3, −6+0+6) = (0,0) ✓. Rank 1 + nullity 2 = 3 columns ✓.
{% endcall %} {% call box('mis') %}"The set of solutions to Ax = b is a subspace." Only when b = 0. For b ≠ 0 the solution set misses the origin, exactly like the set S in 1.1.{% endcall %}

{% call sec('m2-2','2','Orthonormal sets and Hilbert space') %} {% call sub('m2-2-1','2.1','Orthogonality, normalisation and orthonormal sets') %}
Why it matters. With an orthonormal basis, finding the coordinates of a vector needs no equation-solving: each coordinate is one inner product. In quantum mechanics that coordinate is the amplitude, and its squared size is a probability (Module 3).
{% call box('def') %}Two vectors are orthogonal if their inner product is 0. A vector is normalised if its norm is 1 (⟨v|v⟩ = 1). A set {eᵢ} is orthonormal if ⟨eᵢ|eⱼ⟩ = δᵢⱼ (1 if i = j, 0 otherwise). For an orthonormal basis, every vector expands as v = Σ cᵢeᵢ with cᵢ = ⟨eᵢ|v⟩, and ⟨v|v⟩ = Σ|cᵢ|². To normalise a vector, divide it by its norm √⟨v|v⟩.{% endcall %} {% call fig('Expanding v in an orthonormal basis: the coefficient along each axis is the length of the shadow (projection) of v on it. Notice that c₁² + c₂² equals the squared length of v, exactly Pythagoras.') %} {% endcall %} {% call box('ex') %}
Problem. Show e₁ = (1,1,0)/√2, e₂ = (1,−1,0)/√2, e₃ = (0,0,1) are orthonormal, then expand v = (3,1,2).
Orthonormal? ⟨e₁|e₂⟩ = (1 − 1)/2 = 0; ⟨e₁|e₃⟩ = ⟨e₂|e₃⟩ = 0; ⟨e₁|e₁⟩ = (1+1)/2 = 1, ⟨e₂|e₂⟩ = 1, ⟨e₃|e₃⟩ = 1 ✓.
Coefficients. c₁ = ⟨e₁|v⟩ = (3+1)/√2 = 2√2; c₂ = (3−1)/√2 = √2; c₃ = 2.
Check. Σ|cᵢ|² = 8 + 2 + 4 = 14 and ⟨v|v⟩ = 9 + 1 + 4 = 14 ✓. Rebuild: 2√2·(1,1,0)/√2 + √2·(1,−1,0)/√2 + 2(0,0,1) = (2,2,0) + (1,−1,0) + (0,0,2) = (3,1,2) ✓.
{% endcall %} {% call box('mis') %}"Orthogonal vectors are automatically unit vectors." No: (2,0) and (0,3) are orthogonal but not normalised. Another trap with complex vectors: normalise using |cᵢ|², not cᵢ². For (1, i), ⟨v|v⟩ = 1 + 1 = 2 (not 1 + i² = 0).{% endcall %}
Next: 2.2 packages "complex vector space + inner product + completeness" into the Hilbert space; the sin(nπx/L) functions of Module 4 are its orthonormal basis vectors.

{% call sub('m2-2-2','2.2','Hilbert space') %}
Why it matters. The Hilbert space is the stage on which all of quantum mechanics is played: states are vectors in it, observables are operators on it, and probabilities come from its inner product. Wavefunctions ψ(x) are vectors too, with an integral as the inner product.
{% call box('def') %}A Hilbert space ℋ is a complete complex vector space with an inner product. Complete means every sequence of vectors that keeps getting closer together converges to a vector inside the space, so superpositions never leave it. Its dimension can be finite (2 for a qubit's spin) or infinite (position and momentum). For functions, the inner product is ⟨φ|ψ⟩ = ∫ φ*(x) ψ(x) dx, and a state is normalised when ∫|ψ|²dx = 1.{% endcall %}

{% call box('ex') %}
Problem. (a) Normalise ψ(x) = A x(1−x) on [0,1]. (b) Show sin(πx) and sin(2πx) are orthogonal on [0,1].
(a) ∫₀¹ x²(1−x)² dx = ∫(x² − 2x³ + x⁴)dx = 1/3 − 1/2 + 1/5 = (10 − 15 + 6)/30 = 1/30. So A²/30 = 1, giving A = √30.
(b) sin(πx)sin(2πx) = ½[cos(πx) − cos(3πx)]. Integrating over [0,1]: ½[sin(πx)/π − sin(3πx)/(3π)]₀¹ = ½[0 − 0] = 0 ✓.
Check. (a) With A = √30: 30 × 1/30 = 1 ✓ (also confirmed by numerical integration). (b) A second look: the functions have 1 and 2 half-waves, one positive lobe cancelling against the other, consistent with 0.
{% endcall %} {% call box('mis') %}"Hilbert space is just ℝ³ with more dimensions." Two differences matter: the scalars are complex, and the inner product conjugates its first slot. Also, an unnormalised function is a vector but not a valid state until you divide by its norm.{% endcall %}

{% call sec('m2-3','3','Dirac notation, inner, outer and tensor products') %} {% call sub('m2-3-1','3.1','Kets and bras') %}
Why it matters. Dirac notation lets you write a state without committing to a basis, and turns most calculations into mechanical bracket-pushing. Every formula in Modules 3 and 4 uses it.
{% call box('def') %}A ket |ψ⟩ is a vector in the Hilbert space (think: column vector). Each ket has a unique bra ⟨ψ| in the dual space (think: the conjugate transpose, a row vector). The correspondence is antilinear: if |φ⟩ = a|ψ⟩ then ⟨φ| = a*⟨ψ|. In components, ⟨ψ| = (ψ₁*, ψ₂*, …).{% endcall %}

{% call box('ex') %}
Problem. For |ψ⟩ = (2, 1−i)ᵀ write ⟨ψ|, and verify the antilinear rule for a = i.
⟨ψ| = (2*, (1−i)*) = (2, 1+i).
i|ψ⟩ = (2i, i(1−i)) = (2i, i + 1). Its bra is the conjugate: (−2i, 1−i).
Check. a*⟨ψ| = (−i)(2, 1+i) = (−2i, −i − i²) = (−2i, 1 − i) ✓ — the same row. The scalar came out conjugated, as the rule says.
{% endcall %} {% call box('mis') %}"The bra is just the ket written sideways." It is written sideways and conjugated. Forgetting the conjugation turns ⟨ψ|ψ⟩ = Σ|ψᵢ|² into Σψᵢ², which can even be zero for a non-zero vector such as (1, i).{% endcall %}
Next: 3.2 multiplies a bra by a ket to get a number.
{% endcall %}
{% call sub('m2-3-2','3.2','Inner product') %}
Why it matters. ⟨φ|ψ⟩ is the amplitude for finding the state φ when the system is in ψ. Its squared modulus is the probability (Module 3, 3.2).
{% call box('def') %}The inner product ⟨φ|ψ⟩ = Σ φᵢ*ψᵢ is a complex number. Properties: (1) conjugate symmetry ⟨φ|ψ⟩ = ⟨ψ|φ⟩*, so order matters; (2) ⟨ψ|ψ⟩ is real and ≥ 0, and = 0 only for ψ = 0, with norm ‖ψ‖ = √⟨ψ|ψ⟩; (3) Schwarz inequality |⟨φ|ψ⟩|² ≤ ⟨φ|φ⟩⟨ψ|ψ⟩; (4) triangle inequality ‖φ + ψ‖ ≤ ‖φ‖ + ‖ψ‖; (5) orthogonal if ⟨φ|ψ⟩ = 0; orthonormal if also both have norm 1.{% endcall %} {% call fig('Real-space analogue of the Schwarz inequality: |a·b| = |a||b| cos θ ≤ |a||b|. For complex vectors the same bound holds with |⟨a|b⟩|. Equality happens exactly when the vectors are parallel.') %} {% endcall %} {% call box('ex') %}
Problem. For |a⟩ = (1, i, 2)ᵀ and |b⟩ = (2, 1, i)ᵀ find ⟨a|b⟩, ⟨b|a⟩, both norms, and test Schwarz.
⟨a| = (1, −i, 2). ⟨a|b⟩ = 1·2 + (−i)·1 + 2·i = 2 − i + 2i = 2 + i.
⟨b| = (2, 1, −i). ⟨b|a⟩ = 2·1 + 1·i + (−i)·2 = 2 + i − 2i = 2 − i.
⟨a|a⟩ = 1 + 1 + 4 = 6, so ‖a‖ = √6. ⟨b|b⟩ = 4 + 1 + 1 = 6, so ‖b‖ = √6.
Check. ⟨b|a⟩ = (2 + i)* = 2 − i ✓ (conjugate symmetry). Schwarz: |⟨a|b⟩|² = 4 + 1 = 5 ≤ 6·6 = 36 ✓.
{% endcall %} {% call box('mis') %}"⟨a|b⟩ = ⟨b|a⟩." Only for real vectors. In general they are complex conjugates. That is why you must read left-to-right: the left vector is conjugated.{% endcall %}

{% call sub('m2-3-3','3.3','Outer product') %}

{% call box('def') %}The outer product |a⟩⟨b| is the operator that acts as (|a⟩⟨b|)|c⟩ = |a⟩ ⟨b|c⟩ (multiply |a⟩ by the number ⟨b|c⟩). As matrices it is column × row: its (i,j) entry is aᵢ bⱼ*. It is the reverse order of the inner product ⟨b|a⟩, which gives a number.{% endcall %}

Problem. For |a⟩ = (1, i)ᵀ, |b⟩ = (2, 1)ᵀ, find |a⟩⟨b| and apply it to |c⟩ = (1, 1)ᵀ.
⟨b| = (2, 1). |a⟩⟨b| = [[1·2, 1·1],[i·2, i·1]] = {{ mat([['2','1'],['2i','i']]) }}.

Next: 3.4 combines vectors from different spaces.
{% endcall %}
{% call sub('m2-3-4','3.4','Tensor product of vector spaces') %}
Why it matters. A system made of two parts (for example a spin and an orbital motion) lives in the tensor product of the two spaces. It is also how two-qubit states are built.
{% call box('def') %}If V has basis {|αᵢ⟩} (n vectors) and W has basis {|βⱼ⟩} (m vectors), the tensor product V ⊗ W is an nm-dimensional space with basis {|αᵢ⟩⊗|βⱼ⟩}. Rules: (v₁ + v₂)⊗w = v₁⊗w + v₂⊗w; v⊗(w₁ + w₂) = v⊗w₁ + v⊗w₂; (a v)⊗w = v⊗(a w) = a(v⊗w). In components: (a₁,a₂)⊗(b₁,b₂) = (a₁b₁, a₁b₂, a₂b₁, a₂b₂). Products like |ψ⟩|φ⟩ within the same space are not meaningful; the tensor product is for different spaces.{% endcall %} {% call fig('Dimensions multiply: a 2-dimensional space tensor a 2-dimensional space gives 4 basis vectors, one for every pairing. Notice the grid: each cell is one basis vector |αᵢ⟩⊗|βⱼ⟩.') %} {% endcall %} {% call box('ex') %}
Problem. Compute (1,2)ᵀ ⊗ (3,1)ᵀ, and verify the norm rule ⟨v⊗w|v⊗w⟩ = ⟨v|v⟩⟨w|w⟩.
(1·3, 1·1, 2·3, 2·1) = (3, 1, 6, 2).
Norm² of the product: 9 + 1 + 36 + 4 = 50.
Check. ⟨v|v⟩ = 1 + 4 = 5, ⟨w|w⟩ = 9 + 1 = 10, and 5 × 10 = 50 ✓. Extra check: not every 4-vector is a product. (1,0,0,1) would need a₁b₁ = 1, a₂b₂ = 1 but a₁b₂ = 0 = a₂b₁, impossible; such vectors are called entangled (mentioned only to show the product space is bigger than the products).
{% endcall %} {% call box('mis') %}"Tensor product means add the dimensions." It multiplies them (2 ⊗ 2 = 4, not 4 by coincidence: 2 ⊗ 3 = 6, not 5). And "order does not matter": (1,2)⊗(3,1) = (3,1,6,2) but (3,1)⊗(1,2) = (3,6,1,2), a different arrangement of entries.{% endcall %}

{% call sec('m2-4','4','Linear operators and matrix algebra') %} {% call sub('m2-4-1','4.1','Linear operators') %}
Why it matters. Every measurable quantity, every symmetry and every time-evolution step in quantum mechanics is a linear operator. Linearity is what makes superposition survive the operation.
{% call box('def') %}An operator Â is a rule turning a ket into another ket of the same space: Â|ψ⟩ = |φ⟩. It is linear if Â(a₁|ψ₁⟩ + a₂|ψ₂⟩) = a₁Â|ψ₁⟩ + a₂Â|ψ₂⟩. Operator products are associative (ÂB̂)Ĉ = Â(B̂Ĉ) but in general not commutative: ÂB̂ ≠ B̂ Â. The identity operator Î leaves every ket unchanged. Examples: multiplication by x; d/dx; the momentum operator p̂ = −iħ d/dx; the outer product |a⟩⟨b|.{% endcall %} {% call box('ex') %}
Problem. Is Â f = x f linear? Is B̂ f = f² linear?
Â(a f + b g) = x(a f + b g) = a x f + b x g = a Âf + b Âg ✓ linear.
B̂(f + g) = (f + g)² = f² + 2fg + g² ≠ f² + g² = B̂f + B̂g. Not linear.
Check with numbers. Take f = g = 1 (constants): B̂(f + g) = (2)² = 4 but B̂f + B̂g = 1 + 1 = 2 ✗, so B̂ fails linearity, while Â(1 + 1) = 2x = x + x ✓.
{% endcall %} {% call box('mis') %}"ÂB̂ = B̂Â because both are just operations." Order matters. Compare "put on socks, then shoes" with the reverse. In 4.2 you will see a two-line matrix example, and in 7.1 the commutator measures exactly this difference.{% endcall %}

Next: 4.3, 4.4 and 4.5 study the three special classes of operator that quantum mechanics is built on.
{% endcall %}
{% call sub('m2-4-3','4.3','Hermitian operators') %}
Why it matters. Measured values are real numbers. Hermitian operators are exactly the ones guaranteed to have real eigenvalues, which is why Module 3 says every observable is a Hermitian operator.
{% call box('def') %}An operator is Hermitian (self-adjoint) if Â = Â†. For a matrix: A equals its conjugate transpose (real diagonal, Aⱼᵢ = Aᵢⱼ*). Key properties: (1) eigenvalues are real; (2) eigenvectors of distinct eigenvalues are orthogonal; (3) the eigenvectors form a complete orthonormal set; (4) real linear combinations of Hermitian operators are Hermitian; (5) ⟨ψ|Â|ψ⟩ is real.{% endcall %} {% call box('why','Why real eigenvalues follow') %}Suppose Â|a⟩ = λ|a⟩ with ⟨a|a⟩ = 1. Then ⟨a|Â|a⟩ = λ. Take the complex conjugate: λ* = ⟨a|Â|a⟩* = ⟨a|Â†|a⟩ = ⟨a|Â|a⟩ = λ, using Â† = Â. A number equal to its own conjugate is real. (Same style of argument, applied to two eigenvectors, gives orthogonality; see the check below.){% endcall %} {% call box('ex') %}
Problem. Show H = {{ mat([['2','1−i'],['1+i','3']]) }} is Hermitian, find its eigenvalues, and check that the eigenvectors are orthogonal. Then show B = {{ mat([['1','i'],['i','1']]) }} is not Hermitian.
Hermitian: conjugate then transpose: (1−i)* = 1+i in the (2,1) slot and (1+i)* = 1−i in the (1,2) slot, so H† = H ✓; the diagonal (2, 3) is real.
Eigenvalues: Tr H = 5, det H = 6 − (1−i)(1+i) = 6 − 2 = 4. So λ² − 5λ + 4 = 0, giving λ = 1 and λ = 4 (real ✓).
Eigenvectors: λ = 1: (H − I)u = 0 gives u₁ + (1−i)u₂ = 0, so u = (−1 + i, 1). λ = 4: −2v₁ + (1−i)v₂ = 0, so v = (1 − i, 2).
Orthogonal? ⟨u|v⟩ = (−1 − i)(1 − i) + 1·2 = −(1 + i)(1 − i) + 2 = −2 + 2 = 0 ✓.
B: B† = [[1,−i],[−i,1]] ≠ B, so B is not Hermitian.
Check. H u = (2(−1+i) + (1−i)·1, (1+i)(−1+i) + 3) = (−1 + i, −2 + 3) = (−1+i, 1) = 1·u ✓ (using (1+i)(−1+i) = −1 + i − i + i² = −2). H v = (2(1−i) + 2(1−i), (1+i)(1−i) + 6) = (4(1−i), 8) = 4v ✓.
{% endcall %} {% call box('mis') %}"A symmetric matrix is Hermitian." Only if its entries are real. For complex entries you need the conjugate transpose. The matrix B above is symmetric (Bᵀ = B) but not Hermitian.{% endcall %}
Next: 4.4 covers the operators that preserve length, and 4.5 the ones that select components.
{% endcall %}
{% call sub('m2-4-4','4.4','Unitary operators') %}
Why it matters. Probability must stay 1 as a closed system evolves. Unitary operators are the length-preserving ones, so they describe time evolution and every qubit gate (except measurement).
{% call box('def') %}An operator is unitary if Û†Û = ÛÛ† = Î, i.e. its adjoint is its inverse. Consequences: it preserves inner products and norms, ⟨Uφ|Uψ⟩ = ⟨φ|ψ⟩; its eigenvalues have the form eiθ, so |λ| = 1 (they lie on the unit circle); it acts as a rotation in Hilbert space, adding phases to eigenstates. In quantum mechanics: time evolution is unitary, |ψ(t)⟩ = e−iĤt/ħ|ψ(0)⟩, and quantum gates are unitary matrices.{% endcall %} {% call fig('A unitary map is a (complex) rotation: the vector turns but its length does not change. Notice that the two circles are the same size: the norm is preserved, and the probability with it.') %} {% endcall %} {% call box('ex') %}
Problem. Show U = (1/√2)[[1,1],[1,−1]] is unitary, and check it preserves the norm of v = (3,4)ᵀ.
U is real and symmetric, so U† = U. U†U = ½[[1+1, 1−1],[1−1, 1+1]] = ½[[2,0],[0,2]] = I ✓.
Uv = (1/√2)(3+4, 3−4) = (7, −1)/√2. ‖Uv‖² = (49 + 1)/2 = 25.
Check. ‖v‖² = 9 + 16 = 25 ✓. Eigenvalues: tr U = 0 and det U = −½ − ½ = −1, so λ² − 1 = 0, λ = ±1, and |±1| = 1 ✓ (unit modulus). Another example: diag(1, i) has eigenvalues 1 and i, both with modulus 1.
{% endcall %} {% call box('mis') %}"Unitary means Hermitian." Different conditions (U†U = I versus A† = A). Some matrices are both (like the U above), which is why the check can hide the difference; diag(1, i) is unitary but not Hermitian. Also "unitary eigenvalues are real": they only need |λ| = 1.{% endcall %}
Next: 4.5, the projection operator, is the one Module 3 uses to compute measurement probabilities.
{% endcall %}
{% call sub('m2-4-5','4.5','Projection operators') %}
Why it matters. A measurement asks "how much of the state is along this direction?" A projection operator answers exactly that. The probability formula of Module 3 (3.2) is written with it.
{% call box('def') %}A projection operator is Hermitian and idempotent: P̂ = P̂† and P̂² = P̂. For a normalised |u⟩, P̂ = |u⟩⟨u| projects onto the direction of u. Properties: eigenvalues are only 0 and 1; projectors onto orthogonal directions multiply to zero (P̂ᵢP̂ⱼ = 0 for i ≠ j); for an orthonormal basis, Σ|eᵢ⟩⟨eᵢ| = Î (completeness). Probability of finding u in |ψ⟩: ⟨ψ|P̂|ψ⟩ = ‖P̂ψ‖² = |⟨u|ψ⟩|² (for normalised ψ).{% endcall %} {% call fig('P sends v to its shadow Pv along u; what is left over, v − Pv, is perpendicular to u. Notice the right angle: that is what idempotent means geometrically (projecting twice changes nothing).') %} {% endcall %} {% call box('ex') %}
Problem. Let |u⟩ = (1,1)ᵀ/√2 and |v⟩ = (3,1)ᵀ. Build P, check it is a projector, and find the probability of finding u in v.
P = |u⟩⟨u| = ½[[1,1],[1,1]]. P is real symmetric, so P† = P. P² = ¼[[2,2],[2,2]] = ½[[1,1],[1,1]] = P ✓.
Pv = ½(3+1, 3+1) = (2,2). Probability (v is not normalised, so divide): ⟨v|Pv⟩/⟨v|v⟩ = (3·2 + 1·2)/10 = 8/10 = 0.8.
Check. Leftover v − Pv = (1,−1) is orthogonal to u: (1·1 + 1·(−1))/√2 = 0 ✓. The complementary projector P⊥ = ½[[1,−1],[−1,1]] satisfies P + P⊥ = I ✓, and its probability is 1 − 0.8 = 0.2. Direct: P⊥v = ½(3−1, −3+1) = (1,−1), ⟨v|P⊥v⟩ = 3·1 + 1·(−1) = 2, and 2/10 = 0.2 ✓. The two probabilities add to 1.
{% endcall %} {% call box('mis') %}"|u⟩⟨u| projects properly for any u." Only for a normalised u; otherwise P² = ‖u‖²P ≠ P. Also "a projector has any eigenvalues": only 0 (removed directions) and 1 (kept directions).{% endcall %}

{% call sec('m2-5','5','Eigenvalues and eigenvectors') %} {% call sub('m2-5-1','5.1','The eigenvalue equation and how to solve it') %}
Why it matters. The possible results of measuring an observable are the eigenvalues of its operator; the states that give one of those results with certainty are the eigenvectors (Module 3, 1.4). This is the most-used calculation in the whole course.
{% call box('def') %}A non-zero vector |v⟩ is an eigenvector of Â with eigenvalue λ if Â|v⟩ = λ|v⟩: Â only rescales it. Method: (1) solve the characteristic equation det(Â − λÎ) = 0 for λ; (2) for each λ solve (Â − λÎ)|v⟩ = 0 for |v⟩; (3) normalise if required. Problem. Find eigenvalues and normalised eigenvectors of A = {{ mat([['2','−i'],['i','2']]) }}.
Characteristic equation: det(A − λI) = (2−λ)² − (−i)(i) = (2−λ)² − 1 = 0, so 2 − λ = ±1, giving λ = 1 and λ = 3. (Trace 4 = 1 + 3 ✓, det 4 − 1 = 3 = 1·3 ✓.)
λ = 3: (A − 3I)v = 0 → −v₁ − i v₂ = 0, so v₁ = −i v₂. Take v = (−i, 1); norm² = 1 + 1 = 2, so |v₃⟩ = (−i, 1)/√2.
λ = 1: (A − I)v = 0 → v₁ − i v₂ = 0, so v₁ = i v₂. Take v = (i, 1); |v₁⟩ = (i, 1)/√2.
Check. A(−i, 1) = (2(−i) + (−i)(1), i(−i) + 2) = (−3i, 3) = 3(−i, 1) ✓. A(i, 1) = (2i − i, i·i + 2) = (i, 1) ✓. {% endcall %} {% call box('mis') %}"Eigenvectors are unique." Only up to a scalar: (i,1) and 5(i,1) are both fine, and so is eiφ(i,1). Problem. Do σ_z and σ_x commute? What does that mean for measuring spin along z and then x?
