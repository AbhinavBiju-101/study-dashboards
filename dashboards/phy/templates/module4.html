{% call sec('m4-1','1','The particle in a 1D box') %} {% call sub('m4-1-1','1.1','The setup: classical versus quantum') %}
Why it matters. This is the simplest system where the postulates give a complete answer you can compute by hand. It is also a model for electrons confined in tiny structures, so the numbers have real scale.
{% call box('def') %}A particle of mass m is confined to 0 < x < L by infinitely high walls: V(x) = 0 for 0 < x < L, and V = ∞ otherwise. The particle can never be found outside, so ψ = 0 outside. Quantum mechanically, the wavefunction must fit the box and only certain energies survive.{% endcall %} {% call fig('The infinite square well: potential is zero inside and infinite at the walls x = 0 and x = L. Problem. Which of these is a valid "box" potential: (a) V = 0 for 0 < x < L, V = 10 eV outside; (b) V = 0 for 0 < x < L, V = ∞ outside?
(a) finite walls, so the wavefunction leaks into the walls (the subject of tunnelling, Section 5). (b) is the infinite well used in this module.

Next: 1.2 writes the equation that governs the inside of the box.
{% endcall %}
{% call sub('m4-1-2','1.2','The equation inside the box') %}
Why it matters. This reduces the problem to an equation whose solutions you already know from school calculus: sines and cosines.
{% call box('def') %}The time-independent Schrödinger equation (quoted here; its derivation is outside the scope of these notes) is Ĥψ = Eψ, i.e. −(ħ²/2m) d²ψ/dx² + V(x)ψ = Eψ. Inside the box V = 0, so d²ψ/dx² = −(2mE/ħ²)ψ = −k²ψ with k = √(2mE)/ħ. This is the eigenvalue problem for the Hamiltonian operator of Module 3, 1.2: the allowed E are its eigenvalues and the solutions ψ are its eigenfunctions.{% endcall %}
EquationGeneral solution
ψ″ = −k²ψ (k real)A sin kx + B cos kx (oscillating, fits a box)
ψ″ = +κ²ψCeκx + De−κx (grows or decays; cannot vanish at both walls)
{% call box('ex') %}
Problem. Show ψ = sin(kx) satisfies ψ″ = −k²ψ and find the E it corresponds to when k = 2π/L.
ψ′ = k cos kx, ψ″ = −k² sin kx = −k²ψ ✓. E = ħ²k²/2m = ħ²(2π/L)²/2m = 2π²ħ²/(mL²).
Check. Substituting into −(ħ²/2m)ψ″ gives (ħ²k²/2m) sin kx = E·ψ ✓. (Compare with 1.4: this k = 2π/L is n = 2, and E = 4π²ħ²/(2mL²) = 2π²ħ²/(mL²) ✓.)
{% endcall %} {% call box('mis') %}"E can be negative inside the box." With V = 0 inside, E = ħ²k²/2m ≥ 0. A negative E would make k imaginary and the solutions exponential, which cannot be zero at both walls.{% endcall %}
Next: 1.3 applies the wall conditions.
{% endcall %}
{% call sub('m4-1-3','1.3','Boundary conditions and the wavefunction') %}
Why it matters. This is where the quantisation is born. No new physics is added; only "ψ = 0 at the walls" is imposed.
{% call box('def') %}The wavefunction must be continuous, and since ψ = 0 outside the box, ψ(0) = 0 and ψ(L) = 0. Take ψ = A sin kx + B cos kx. At x = 0: ψ(0) = B = 0, so ψ = A sin kx. At x = L: A sin kL = 0, and A ≠ 0 (else ψ ≡ 0), so sin kL = 0 ⇒ kL = nπ, n = 1, 2, 3, … Hence kₙ = nπ/L. n = 0 gives ψ ≡ 0 (no particle), and negative n only flips the sign of ψ (same state).{% endcall %} {% call fig('Only waves that fit the box with zero at both ends are allowed: n = 1, 2, 3 are shown. Notice each has exactly n half-wavelengths inside the box. A wave with a non-whole number of half-waves (such as 2.5) cannot be zero at both walls, as the example below shows.') %} {% endcall %} {% call box('ex') %}
Problem. Would k = 2.5π/L be allowed? What is ψ(L) for it?
ψ = A sin(2.5πx/L), so ψ(L) = A sin(2.5π) = A·sin(π/2) = A ≠ 0.
Check. Since ψ(L) ≠ 0 the boundary condition fails, so k = 2.5π/L is not allowed: kL must be a whole multiple of π ✓ (n = 2.5 is not an integer).
{% endcall %} {% call box('mis') %}"Both the sine and the cosine solutions survive." The cosine is killed at x = 0 (cos 0 = 1 ≠ 0). For a box from −L/2 to L/2 the roles swap, but here the walls are at 0 and L.{% endcall %}
Next: 1.4 converts kₙ into energies.
{% endcall %}
{% call sub('m4-1-4','1.4','Energy eigenvalues') %}
Why it matters. This formula is what almost every numerical problem in the module uses.
{% call box('def') %}From kₙ = nπ/L and E = ħ²k²/2m: Eₙ = n²π²ħ²/(2mL²) = n²h²/(8mL²), n = 1, 2, 3, … (using ħ = h/2π). The ground state is E₁ = h²/(8mL²), and Eₙ = n²E₁ (ratios 1 : 4 : 9 : 16 …). Energy is quantised, with n the quantum number. Shrinking the box (L smaller) or using a lighter particle (m smaller) raises the energies.{% endcall %} {% call fig('Energy levels of the box, drawn to scale: Eₙ = n²E₁. Notice the gaps grow with n (3E₁, 5E₁, 7E₁…), unlike the equal spacing of a spring.') %} {% endcall %} {% call box('ex') %}
Problem. An electron (m = 9.109×10⁻³¹ kg) is in a box of width L = 0.5 nm. Find E₁, E₂, E₃ in eV and the wavelength of a photon emitted in the n = 2 → 1 transition. (h = 6.626×10⁻³⁴ J·s, 1 eV = 1.602×10⁻¹⁹ J.)
E₁ = h²/(8mL²) = (6.626×10⁻³⁴)²/(8 × 9.109×10⁻³¹ × (0.5×10⁻⁹)²) = 4.390×10⁻⁶⁷ / 1.822×10⁻⁴⁸ = 2.41×10⁻¹⁹ J = 1.50 eV.
E₂ = 4E₁ = 6.02 eV, E₃ = 9E₁ = 13.5 eV. ΔE(2→1) = 3E₁ = 4.51 eV.
λ = hc/ΔE ≈ 1239.8 eV·nm / 4.51 eV ≈ 275 nm (ultraviolet).
Check. Units: h²/(mL²) is J²s²/(kg m²) = J ✓. Ratios 1 : 4 : 9 ✓. Independent route: for n = 1, p = h/2L gives E = p²/2m = the same 1.50 eV (see 2.5).
{% endcall %} {% call box('mis') %}"Eₙ ∝ n" or "Eₙ ∝ n²/L". It is ∝ n²/L². Also a caution from your problem deck: its worked answers for an electron in a 1 Å box (5.68 eV and, in another slide, 0.58 eV) do not agree with their own working. With the deck's constants h²/(8ma²) = 6.03×10⁻¹⁸ J ≈ 37.6 eV for a = 1 Å; the deck's other problem, a 0.25 nm well (about 6 eV), is consistent with the formula. These notes use the formula. If your exam material follows the deck's number instead, go with that and let me know.{% endcall %}

{% call sub('m4-1-5','1.5','Normalisation and the eigenfunctions') %}
Why it matters. A probability must total 1. Normalisation gives the final, usable ψₙ and makes the set an orthonormal basis (Module 2, 2.1).
{% call box('def') %}Require ∫₀ᴸ|ψ|²dx = 1. With ψ = A sin(nπx/L): A²∫₀ᴸ sin²(nπx/L)dx = A²·L/2 = 1, so A = √(2/L) and ψₙ(x) = √(2/L) sin(nπx/L), 0 < x < L. The ψₙ are orthonormal: ∫ψₘψₙdx = δₘₙ (the m ≠ n integral vanishes, as verified in Module 2, 2.2).{% endcall %} {% call box('why','Why the integral is L/2') %}sin²θ = (1 − cos 2θ)/2. Over a whole number of half-waves, the cos term integrates to zero, leaving half the length: ∫₀ᴸ sin²(nπx/L)dx = L/2, independent of n.{% endcall %} {% call box('ex') %}
Problem. Find A for a box of width L = 2 nm, and ψ₁ at x = 0.5 nm.
A = √(2/L) = √(2/2 nm) = 1 nm^(−1/2). ψ₁(0.5 nm) = 1 · sin(π·0.5/2) = sin(π/4) = 0.707 nm^(−1/2).
Check. Units: |ψ|² has units 1/length, so that ∫|ψ|²dx is dimensionless ✓. Numerical check: A²(L/2) = 1 × 1 nm⁻¹ × 1 nm = 1 ✓.
{% endcall %} {% call box('mis') %}"A = 1/√L" or "A = 2/L". The factor is √(2/L) because the average of sin² is ½. Always check with A²·L/2 = 1.{% endcall %}

Next: 2.2 explains why n = 0 is forbidden and what that means.
{% endcall %}
{% call sub('m4-2-2','2.2','Zero-point energy') %}
Why it matters. It is the simplest demonstration that a confined quantum particle can never be at rest.
{% call box('def') %}The lowest allowed energy is E₁ = h²/(8mL²) > 0, because n = 0 gives ψ ≡ 0. This zero-point energy is forced by the uncertainty principle: confining the particle to width ~L gives Δx ≲ L, so Δp ≳ ħ/2L, and a non-zero Δp means non-zero kinetic energy. It scales as 1/L² (tighter confinement, larger zero-point energy).{% endcall %} {% call box('ex') %}
Problem. Compare the zero-point energy of an electron in a 1 nm box with that of a 1 g ball in a 10 cm box.
Electron: E₁ = 4.390×10⁻⁶⁷ / (8 × 9.109×10⁻³¹ × 10⁻¹⁸) = 6.02×10⁻²⁰ J = 0.376 eV.
Ball: E₁ = 4.390×10⁻⁶⁷ / (8 × 10⁻³ × 10⁻²) = 5.5×10⁻⁶³ J.
Check. The ratio is 10⁴³: for macroscopic objects the quantisation is far too small to see, consistent with why nobody notices it in everyday life. Dimension check: both in joules ✓.
{% endcall %} {% call box('mis') %}"Zero-point energy means the particle is moving at its lowest speed and could be slowed to 0." It cannot be lowered further: E₁ is the minimum allowed by the wave's shape.{% endcall %}
Next: 2.3 looks at where the particle can be found.
{% endcall %}
{% call sub('m4-2-3','2.3','Nodes, antinodes and probability density') %}
Why it matters. The probability density |ψ|² is the quantity you integrate in every "find the probability" question, and its shape contradicts the classical uniform distribution.
{% call box('def') %}ψₙ has n − 1 interior nodes (zeros) at x = jL/n, j = 1,…,n−1, and n antinodes (maxima of |ψ|²) at x = (2j − 1)L/2n. The probability density is |ψₙ|² = (2/L) sin²(nπx/L). It is zero at the nodes: the particle is never found there. Counting convention: these notes count only interior nodes (n − 1). Your question bank counts the two walls as nodes too, so there n = 1 has 2 nodes and ψₙ has n + 1 nodes (n antinodes either way). Same physics; read the question to see which counting it uses.{% endcall %} {% call fig('ψₙ (top row) and |ψₙ|² (bottom row) for n = 1, 2, 3, computed from the formula. Notice n = 2 has a node at the centre, so the particle is never found in the middle of the box in that state.') %} {% endcall %} {% call box('ex') %}
Problem. For n = 3 locate the nodes and the antinodes.
Nodes: sin(3πx/L) = 0 ⇒ x = L/3, 2L/3 (and the walls 0, L). Antinodes: |sin| = 1 ⇒ 3πx/L = π/2, 3π/2, 5π/2 ⇒ x = L/6, L/2, 5L/6.
Check. Count: n − 1 = 2 interior nodes ✓; n = 3 antinodes ✓; nodes and antinodes alternate along the box (L/6 < L/3 < L/2 < 2L/3 < 5L/6) ✓.
{% endcall %} {% call box('mis') %}"The walls are nodes, so the count of nodes is n." Interior nodes are n − 1 (the wall zeros are not counted). Also: "at a node the particle cannot cross it"; it can be found on either side, just never exactly at a node.{% endcall %}
Next: 2.4 turns |ψ|² into actual probabilities.
{% endcall %}
{% call sub('m4-2-4','2.4','Probability in a region and the correspondence principle') %}
Why it matters. "Find the probability between a and b" is a standard exam question, and the large-n limit shows quantum mechanics recovering the classical result.
{% call box('def') %}The probability of finding the particle between a and b is P = ∫ₐᵇ|ψₙ|²dx = (2/L)∫ₐᵇ sin²(nπx/L)dx. For large n, |ψₙ|² oscillates so fast that P → (b − a)/L, the uniform classical value (correspondence principle: at large quantum numbers quantum predictions approach classical ones).{% endcall %} {% call box('ex') %}
Problem. Find P for the middle third (L/3 < x < 2L/3) for n = 1 and n = 2.
P = (1/L)∫(1 − cos(2nπx/L))dx = [x/L − sin(2nπx/L)/(2nπ)] between the limits = 1/3 − [sin(4nπ/3) − sin(2nπ/3)]/(2nπ).
n = 1: sin(4π/3) = −√3/2, sin(2π/3) = +√3/2, so P = 1/3 + √3/(2π) = 0.333 + 0.276 = 0.609. n = 2: sin(8π/3) = +√3/2, sin(4π/3) = −√3/2, so P = 1/3 − √3/(4π) = 0.333 − 0.138 = 0.196.
Check. n = 1 is peaked at the centre, so more than the classical 1/3 ✓. n = 2 has a node at the centre, so less than 1/3 ✓. Both confirmed by numerical integration. Large n: the oscillating term shrinks like 1/n, so P → 1/3 ✓.
{% endcall %} {% call box('mis') %}"The probability in a region is |ψ|² at its midpoint." You must integrate. Also "P = (b−a)/L for every n": only in the classical (large n) limit.{% endcall %}

{% call sub('m4-2-5','2.5','The standing-wave (de Broglie) picture') %}
Why it matters. It is a quick cross-check that catches algebra slips and shows why quantisation arises: waves that fit.
{% call box('def') %}A wave that vanishes at both walls must fit a whole number of half-wavelengths: L = nλ/2, so λ = 2L/n. With de Broglie's p = h/λ = nh/2L, and E = p²/2m = n²h²/(8mL²), exactly the result of 1.4.{% endcall %} {% call box('ex') %}
Problem. Verify E₁ for the electron in the 0.5 nm box from its de Broglie wavelength.
n = 1: λ = 2L = 1.0 nm; p = h/λ = 6.626×10⁻³⁴ / 10⁻⁹ = 6.63×10⁻²⁵ kg·m/s.
E = p²/2m = (6.63×10⁻²⁵)² / (2 × 9.109×10⁻³¹) = 2.41×10⁻¹⁹ J = 1.50 eV.
Check. Matches E₁ = 1.50 eV from 1.4 ✓ — two independent routes agree.
{% endcall %} {% call box('mis') %}"L = nλ" (full wavelengths). The condition is half-wavelengths, because the wave must be zero (not just repeat) at each wall.{% endcall %}

{% call sec('m4-3','3','Extension to two and three dimensions') %} {% call sub('m4-3-1','3.1','Separation of variables in a box') %}
Why it matters. A real confined electron (a quantum dot, a metal block) lives in three dimensions, and the 1D result builds the 3D one almost for free.
{% call box('def') %}For a rectangular box 0 < x < a, 0 < y < b, 0 < z < c with V = 0 inside and ∞ outside, the equation is −(ħ²/2m)(∂²/∂x² + ∂²/∂y² + ∂²/∂z²)ψ = Eψ. Try a product ψ = X(x)Y(y)Z(z). Dividing by XYZ splits the equation into three 1D equations, each with its own separation constant, and E = Eₓ + E_y + E_z. Each factor obeys its own walls, exactly like the 1D box.{% endcall %} {% call fig('Separation of variables: one 3D problem becomes three independent 1D problems whose energies add. Problem. An electron is in a 2D square box of side L (take the z-direction as absent). Write ψ and E in terms of nₓ and ny, and find the lowest two energies in units of E₀ = h²/(8mL²).
ψ = (2/L) sin(nₓπx/L) sin(n_yπy/L), E = E₀(nₓ² + n_y²).
Lowest: (1,1) gives 2E₀. Next: (1,2) or (2,1) give 5E₀.
Check. Normalisation: (2/L)² × (L/2)(L/2) = 1 ✓. Each 1D factor is the ψₙ of 1.5 ✓. (That (1,2) and (2,1) have the same energy is a coincidence of the square shape; the general treatment of this is degeneracy, Section 4.)
{% endcall %} {% call box('mis') %}"E = Eₓ · E_y · E_z" or "ψ = ψₓ + ψ_y + ψ_z". The wavefunctions multiply and the energies add.{% endcall %}

{% call sub('m4-4-1','4.1','What degeneracy means') %}
Why it matters. In 1D every level was a single state. In 3D, several different wavefunctions can have exactly the same energy. Counting them is a standard exam task and it also tells you how many electrons a level can hold.
{% call box('def') %}Energy levels are degenerate if the same energy is obtained from more than one quantum state. The number of states at one energy is the degree of degeneracy. A level with only one wavefunction is non-degenerate. Example from your slides: (nₓ, ny, nz) = (2,1,1), (1,2,1), (1,1,2) in a cube all have E = 6h²/8mL², three different wavefunctions, so the level is 3-fold degenerate. Degeneracy reflects an underlying symmetry: a cube has three equivalent directions.{% endcall %}

Why it matters. "Find the degree of degeneracy of the level with energy …" is answered by one procedure: list every triple of positive integers with the right sum of squares.

{% call sub('m4-4-3','4.3','Symmetry and breaking the degeneracy') %}
Why it matters. The degeneracy came from the cube's symmetry. Remove the symmetry and the levels split, which is how real systems show fine structure.
{% call box('def') %}For a box with sides a, b, c: E = (π²ħ²/2m)(nₓ²/a² + n_y²/b² + n_z²/c²) (the slides' form with ħ, equivalent to the h²/8m form in 3.2). If the sides differ, permuting the quantum numbers changes the energy, so the permutation degeneracy is broken. A box with two equal sides keeps the degeneracy between those two directions only.{% endcall %} {% call fig('One level splitting when the cube is stretched along z (c = 2L, a = b = L). Notice the state that was stretched, (1,1,2), moves down; the other two stay together because a = b still holds.') %} {% endcall %} {% call box('ex') %}
Problem. A box has a = b = 1 nm and c = 2 nm. Find the energies of (2,1,1), (1,2,1) and (1,1,2) in eV and say whether the level is still degenerate.
E = 0.376 eV × (nₓ²/a² + n_y²/b² + n_z²/c²) with a = b = 1 and c = 2 (in units of 1 nm): (2,1,1): 4 + 1 + ¼ = 5.25 → 1.97 eV. (1,2,1): 1 + 4 + ¼ = 5.25 → 1.97 eV. (1,1,2): 1 + 1 + 1 = 3 → 1.13 eV.
So the old 3-fold level has split into a 2-fold level (1.97 eV) and a non-degenerate level (1.13 eV).
Check. With c = L the three energies were all 2.26 eV (4.1), so the splitting comes only from c ≠ a. The remaining pair is degenerate because a = b, the symmetry that is left ✓. Making all three sides different would split that pair too.
{% endcall %} {% call box('mis') %}"Degeneracy is removed by making the box bigger." Size alone does not matter (a bigger cube still has the same pattern 1, 3, 3, …); what matters is the loss of symmetry between directions.{% endcall %}

{% call sub('m4-5-1','5.1','Classical versus quantum behaviour at a barrier') %}
Why it matters. This is the headline result of the module: a particle with E < V₀ is not stopped dead by a barrier. A ball rolling at a hill it cannot climb always comes back; an electron wave leaks through.
{% call box('def') %}Quantum tunnelling is the passage of a particle through a potential barrier whose height V₀ exceeds the particle's energy E. Classically this region is forbidden (it would need negative kinetic energy E − V₀ < 0), so the classical particle is always reflected. Quantum mechanically, the particle's wavefunction is not zero inside the barrier and continues beyond it, so there is a small but finite probability to find the particle on the far side. The energy of a transmitted particle is unchanged; only the amplitude is reduced (your slide 8: "reduced probability, but not reduced energy").{% endcall %}

{% call sub('m4-5-2','5.2','The barrier problem: regions, wave numbers and solutions') %}
Why it matters. Everything about tunnelling follows from solving the time-independent Schrödinger equation (Module 3, §5) separately in three regions and joining the pieces.
{% call box('def') %}A particle of energy E comes from the left on a rectangular barrier of height V₀ and width L (V = 0 for x < 0 and x > L, V = V₀ for 0 < x < L). The incident wave is Aeikx, the reflected wave Be−ikx, the transmitted wave Feikx; with nothing coming from the right, G = 0.{% endcall %}

Next: 5.3 turns the amplitudes into probabilities.

{% call sub('m4-5-3','5.3','Reflection and transmission probabilities') %}
Why it matters. R and T are what you are asked to compute: the fraction reflected and the fraction transmitted.
{% call box('def') %}R = |ψI(reflected)|²/|ψI(incident)|² = B*B/A*A and T = |ψIII(transmitted)|²/|ψI(incident)|² = F*F/A*A. Every particle is either reflected or transmitted, so R + T = 1. Problem. For a barrier, B*B/A*A = 0.235. Find T and say what fraction of 1000 incident particles is transmitted.

Why it matters. The STM is the standard worked application: it uses the exponential sensitivity of T to see single atoms.
